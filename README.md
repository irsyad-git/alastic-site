# alastic.id

Company website for **Alastic** (PT Alastic Global Industries): simple, private software.

Static HTML/CSS served by GitHub Pages at [alastic.id](https://alastic.id) (`CNAME`).

| Page | What it is |
|---|---|
| `index.html` | Home and app list |
| `about.html` | About the company |
| `privacy.html` | Company privacy policy |
| `rebahan-alert.html` | Rebahan Alert service info and terms (Indonesian) |
| `style.css`, `assets/` | Shared styles, logos and app icons |

Edit a page and push to `main`; GitHub Pages republishes in about a minute. Contact: contact@alastic.id

Kebijakan Privasi

Terakhir diperbarui: Oktober 2026

Kebijakan ini menjelaskan bagaimana PT Alastic Global Industries ("Alastic", "kami") menangani informasi di situs web ini. Setiap produk kami juga memiliki kebijakan privasinya sendiri, yang berlaku saat kamu memakai produk tersebut.

Situs web ini

Situs web ini di-host di GitHub Pages, yang dapat menyimpan log teknis standar (seperti alamat IP) untuk keamanan dan operasional sesuai kebijakan privasi GitHub sendiri.

Halaman beranda, Tentang, dan panduan dapat menampilkan iklan dari Google AdSense. Google dan mitranya dapat menggunakan cookie atau teknologi serupa untuk menampilkan dan mengukur iklan, termasuk iklan berdasarkan kunjunganmu ke situs ini dan situs lain. Kamu dapat mengatur personalisasi iklan di pengaturan iklan Google, dan mempelajari cara Google memakai data dari situs mitra di kebijakan situs mitranya. Kami tidak menjalankan analitik atau pelacakan lain di situs web ini.

Saat kamu menghubungi kami

Jika kamu mengirim email, kami memakai alamat email dan pesanmu hanya untuk membalasmu. Kami tidak menjual atau membagikan informasi ini.
